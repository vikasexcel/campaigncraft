# CampaignCraft ![Build Status](https://img.shields.io/badge/build-passing-brightgreen) ![Version](https://img.shields.io/badge/version-1.0.0-blue)

## Project Description
CampaignCraft is a beginner-friendly web application that allows users to create and manage email marketing campaigns with ease. Users can select from a variety of templates, segment their audience based on simple criteria, and view basic analytics to track campaign performance.

## Features
- ✉️ Template-based email creation
- 🎯 Basic audience segmentation
- 📊 Simple analytics dashboard

## Tech Stack
### Frontend
- **Node.js** 🟢

### Database
- **MongoDB** 🐱‍💻

## Installation
To set up CampaignCraft locally, follow these steps:

- Clone the repository:
  bash
  git clone https://github.com/vikasexcel/campaigncraft
  - Navigate into the project directory:
  bash
  cd campaigncraft
  - Install the required dependencies:
  bash
  npm install
  - Set up your MongoDB database (ensure MongoDB is running):
  bash
  mongod
  - Start the application:
  bash
  npm start
  ## Usage
Once the application is running, navigate to `http://localhost:3000` in your web browser. You can start creating email campaigns, segmenting your audience, and viewing analytics.
